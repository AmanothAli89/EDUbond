# FIREBASE CONFIGURATION GUIDE: EDUBOND

This document details the Firebase configuration, collection schemas, authentication settings, and security rules for EduBond in Flutter.

---

## 1. Project & Application Identifiers

- **Firebase Project:** Existing EduBond project (used by original Kotlin app).
- **Android Package / Application ID:** `com.example.peermatrix`
- **Configuration File:** `android/app/google-services.json`
- **FlutterFire Options File:** `lib/firebase_options.dart` (generated by FlutterFire CLI).

## 3. Production Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Admin credentials: read allowed for authentication verification; write disabled
    match /admin_config/{docId} {
      allow read: if request.auth != null;
      allow write: if false;
    }

    // User profiles: users can update own profile, admins can moderate
    match /users/{userId} {
      allow read: if request.auth != null;
      allow create, update: if request.auth != null && (request.auth.uid == userId || request.auth.token.admin == true);
      allow delete: if request.auth != null && request.auth.token.admin == true;
    }

    // Subjects: readable by all authenticated users; modified by admin
    match /subjects/{subjectId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.token.admin == true;
    }

    // Quizzes: readable by all authenticated users; modified by admin
    match /quizzes/{subject} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.token.admin == true;
    }

    // Groups & Messages
    match /groups/{groupId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null;

      match /messages/{messageId} {
        allow read, create, update, delete: if request.auth != null;
      }
    }

    // Join and Teacher Requests
    match /group_join_requests/{id} {
      allow read, write: if request.auth != null;
    }

    match /teacher_group_requests/{id} {
      allow read, write: if request.auth != null;
    }

    match /subject_requests/{id} {
      allow read, write: if request.auth != null;
    }

    match /user_roles/{id} {
      allow read, write: if request.auth != null;
    }

    match /quiz_attempts/{id} {
      allow read, write: if request.auth != null;
    }
  }
}
```
